# Cheatsheet — Offer Design

## Decision rules

| Situation | Do this | Because |
|---|---|---|
| "You're too expensive" / constant comparison | Break comparability (scope, model, guarantee, terms, name) | Like-for-like = cheapest wins by default |
| Thin margins, full client load | Raise price + add bonuses, don't cut cost first | It's a positioning problem, not a cost problem |
| Traffic but low conversion | Score the 4 value drivers; fix the weakest | Value is a ratio, not a feature list |
| Not sure which value driver to fix | Attack time-to-result and effort first | People pay most for speed and done-for-you |
| Market has pain + budget + reach but is shrinking | Change markets | A great offer can't beat a declining market |
| Tempted to switch target markets | Commit and run real trial and error | Switching restarts your learning from zero |
| Closing a deal | Add a bonus, never discount the core offer | Discounting signals weakness, trains negotiation |
| High delivery cost | Conditional or all-sales-final guarantee | You'd otherwise eat refund + delivery cost |
| First version of an offer | Over-deliver, then systematize | Make sales and learn first, protect margin later |
| Response to an old offer fading | Rename it, don't rebuild it | It's offer fatigue — you're changing the wrapper |
| One-to-one sale | Ask for the sale first, reveal bonuses after yes | Bonuses become a delight, not the reason to buy |

## The perceived-value formula
value ≈ ( desired result × confidence it will work ) ÷ ( time to result × effort required )
- raise numerator: vivid outcome, proof, case studies, credentials, guarantees
- lower denominator: faster results / fast early wins, done-for-you, tools, templates, accountability

## Four guarantee types
| Type | Shape | Best for |
|---|---|---|
| Unconditional | no-questions refund in a window | low delivery cost, max buyers |
| Conditional | remedy *if* they did the agreed actions | default; also drives results |
| All-sales-final | no refunds + credible reason | consumables, high delivery cost |
| Performance-based | paid on results | aligning incentives |

Format: **"If not [result] in [timeframe], then [remedy]."** Prefer "better than money back."

## Thresholds & heuristics
- Target price ≈ a large multiple of delivery cost (5–10×+ where value supports it), not 2–3×.
- Guarantee math: +30% sales with refunds doubling 5%→10% still nets ~1.23× revenue.
- Offer name: 3–5 of { reason, audience, result, timeframe, format }; keep it short; test written.
- Leverage order: market demand > offer strength > persuasion skill.
- Bonus stack: total stated value should clearly dwarf the price.

## Weak-offer tells
- You explain *why you're different* instead of the offer showing it
- Buyers ask "what's the price?" before "what do I get?"
- You discount to close
- No deadline, no cap, no guarantee, a generic category name
- You're the cheapest option and still losing deals

## Build sequence (memorize)
Market → desired outcome → obstacle list → solutions → delivery methods → cut & bundle →
scarcity → urgency → bonuses → guarantee → name.
