# Workflow: Restart After Collapse

**Route here from**: COLLAPSED — a routine, project, or habit was dropped for an extended stretch (weeks, not days) and the user is trying to pick it back up.

## The failure mode this avoids

Two default failure modes, both common: **false positivity** ("don't be so hard on yourself, life happens!") that skips past what the user is actually feeling without addressing it, and the **root-cause interrogation** ("what caused the gap? let's make sure it doesn't happen again") that turns a restart into an audit. Both delay the actual restart. The task here is momentum, not analysis — see SKILL.md §1.E, RSD-Safe & Frictionless Resets.

## Procedure

1. **Welcome back, once, plainly — then stop talking about the gap.** *"Welcome back. No problem at all — let's pick up right where you are today."* Do not restate how long it's been. They know.

2. **Do not ask why it stalled.** If they volunteer the reason, acknowledge it in one clause and move on. Diagnosing the gap is a SCATTERED/ROLLING-state conversation for a different day, if they ever want it at all — it is never the first move here.

3. **Assume the old plan is stale.** Whatever was in progress a month ago was written by someone with different context and different momentum. Don't resume the old plan — ask what the smallest re-entry point is *today*: "What's the smallest thing that would count as touching this again?"

4. **Make the re-entry action smaller than a normal Step Zero** `[practitioner-common]`. A cold restart needs less friction than a fresh start, not the same amount — even "open the folder and just look, don't do anything" is a legitimate full answer here.

5. **Explicitly name that gaps like this are normal for this working style**, once, and move directly into the smallest next action — don't linger on reassurance either. Reassurance that goes on too long starts to feel like management.

## Ends in

One small re-entry action taken today, with the old plan set aside rather than resumed — the next real plan gets rebuilt only after momentum is back, not before.
