Tenant File Checker

Screens a rental application package for signs of edited credit reports and documents that don't agree with each other.

Files stay on this computer. Only the summary below is meant to be shared.

1. Application files

A zip from email works. The checker reads the files on this computer and fills in step 2 for you. Screenshots are read with on-device text recognition (first use downloads the recognition engine; your files are not uploaded).

2. What the application says

All fields are optional. The checker fills in what it can read from the files. Check each value, correct anything misread, and fill in blanks if you know them. Fewer details means fewer cross-checks, not a problem with the applicant.

Date of birth, address and salary are only used on this computer. They are never put in the summary.

4. Salary check

Paste the salary range your AI assistant found for this job title and city. The comparison happens here; the salary is never shared.
