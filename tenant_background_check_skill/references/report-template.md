# Report template

Use these sections, in this order. Plain language; one line per finding.

```
## Red flags
- <finding> — <why it matters> (source: checker flag CODE / link)

## Soft flags
- <finding> — <what to ask or check>

## Could not verify
- <what could not be checked and why>

## Questions to ask the applicant
1. ...

## Recommended next step
<one of:>
- Stop here: <red flag> needs an explanation before spending more time.
- Ask for <document> sent directly from <source>, then re-run the checker.
- No red flags found: run the paid screening check (FrontLobby or equivalent) before deciding.
```

Rules:

- Recommend the paid screening check only when there are **no red flags**.
- Never write "genuine", "authentic", or "verified identity". Say "no flags
  found" instead.
- Every web finding carries its link.
