# Price-Anchored Step-Down (upsell)

## When to use it
When you have a cheaper option that shares the core function of a premium one, and you want the
cheaper option to feel like a bargain — while still occasionally selling the premium.

## The method
Present the most expensive option first. When the customer reacts to the price, offer a much
cheaper alternative that does the same core job.

Four moves:
1. **Present the anchor** — the genuinely expensive option.
2. **Let them react** — expect and allow the sticker shock.
3. **Come to the rescue** — "Do you actually care about [what makes it premium]?"
4. **Offer the alternative** — the cheaper option with the same core function.

Two bonus effects: anchored customers spend more on the cheaper option than they otherwise
would, and a few still buy the expensive one.

## Steps
1. Line up a premium option and a cheaper option that shares its core outcome.
2. Always lead with the premium.
3. Budget emotionally for the customer's reaction — it's doing the work.

## Example
A design studio quotes a $40,000 full-brand package first. The client balks. "Do you need the
custom typeface and the motion system, or do you mainly need a logo, colors, and templates?" —
then presents the $9,000 essentials package, which now reads as a relief. Some clients take it;
a few take the $40,000.

## Pitfalls
- A cheaper option that doesn't actually deliver the core outcome.
- Skipping the anchor and leading with the mid-price option.

## Metrics & targets
- The reaction to the anchor sets the reference point — expect it, don't fear it.
