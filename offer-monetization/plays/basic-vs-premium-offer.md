# Basic-vs-Premium Side-by-Side Offer (attraction)

## When to use it
Almost any business. Especially useful when price-sensitive leads would otherwise walk.

## The method
Advertise a cheap or free basic version. When leads engage, present it *next to* a more valuable
premium version, and emphasize the premium one. Either choice is a win: premium = cash now;
basic = a customer you can upgrade later instead of a lost lead.

Two steps:
1. Advertise a smaller, simpler version as the entry point.
2. When leads respond, show both options side by side, leaning on the premium.

Build the basic version by subtracting from the premium: fewer components, older models, no
support, no guarantee, self-serve delivery, group instead of one-to-one.

## Steps
1. Define your premium offer fully.
2. Strip it down to a credible basic version.
3. Advertise the basic version; on contact, present both, emphasizing premium.
4. Put basic-takers on an upgrade path (`next-problem-upsell`).

## Example
A fitness studio advertises "Free 21-Day Reset." On the intro call: **basic** = daily workouts
in an app, generic meal plan, no coaching, no guarantee; **premium** = unlimited classes,
personalized nutrition, 1-on-1 accountability, results guaranteed. Some take premium (cash now);
the rest stay in the ecosystem for a later upgrade.

## Pitfalls
- Advertising the premium version instead of the basic one.
- Hard-selling the basic version — its job is to make premium look obvious.
- No follow-up path for basic-takers.

## Metrics & targets
- You close nearly everyone into *something*, which lowers effective acquisition cost.
